# 美学指南 — 冰山主图风格

> 本指南描述「中文兔子洞冰山图」主图的视觉语言，并给出界面、背景与动效的落地规范。
> 主题一句话：**亮橙色的落日点燃深蓝色的冰海；冰面之上克制清冷，水面之下流动幽深。**

## 1. 核心意象

主图由四个意象构成，所有界面都从这四个意象派生：

| 意象 | 视觉来源 | 设计含义 |
| ---- | ---- | ---- |
| 落日 | 天空顶部亮橙 → 橙红渐变 | 好奇心、入口、焦点 |
| 冰面 | 非对称双峰冰山，冷白 / 冰蓝受光面 | 秩序、知识表层、可读内容 |
| 水面 | 约 30% 高度的波浪折线 | 认知门槛、表层与深层分界 |
| 深海 | 蓝 → 蓝黑 → 纯黑的水下体量 | 未知、数据深度、沉浸感 |

设计时先问三件事：

1. 这个元素属于「冰面之上」还是「水面之下」？冰上偏冷白克制，水下偏蓝黑流动。
2. 它是否需要吸引注意？只有关键动作和当前状态可以点亮橙色。
3. 它是容器还是内容？容器应当像「冻结的玻璃」，内容才是发光的实体。

## 2. 主题色

### 2.1 五个选择色

| # | 名称 | 色值 | 用途 |
| - | ---- | ---- | ---- |
| 1 | 亮橙 | `#ff6a06` | 唯一强调色：CTA、当前态、收藏、NEW、焦点环 |
| 2 | 橙光 | `#ffb36f` | hover / 日落反光 / 柔和提示 |
| 3 | 深海蓝 | `#0a5a99` | 海面 / 液态 / 水体主色 |
| 4 | 冰蓝 | `#7db5dc` | 冰面受光 / 次级信息 / 阴影面 |
| 5 | 纯黑 | `#000000` | 黑海 / 夜空 / 页面最深色、渐变终点 |

> 白透明度（`--white-*`）与近黑表面（页面 `#050505`、弹窗 `#111111`）是中性色，不计入五个主色。新增颜色时必须先问：能否用这五个色或中性色解决？

### 2.2 比例纪律

- **纯黑 + 深海蓝占 60%**：页面基底、背景、容器。黑色是黑海，深蓝是海水，两者可以互相过渡。
- **白透明度 + 冰蓝占 30%**：文本、边框、结构线、次级信息。
- **亮橙 + 橙光只占 10% 以下**：橙色是信号，不是装饰色。大面积橙色会让「坠落感」消失。
- 橙与蓝不做 50/50 对撞；它们的关系是「一点橙光落在蓝海上」，不是分屏对比。
- 不要因为内容少就提亮整体；黑海是默认状态，不是「没设计」。

### 2.3 主图渐变

所有渐变只从五个选择色中取色。

天空（自上而下，亮橙 → 深海蓝 → 黑）：

```css
linear-gradient(
  to bottom,
  #ff6a06 0%,   /* 落日 */
  #ffb36f 18%,  /* 橙光余晖 */
  #0a5a99 55%,  /* 海面暮色 */
  #000000 100%  /* 黑海 */
)
```

水下（冰蓝 → 深海蓝 → 黑）：

```css
linear-gradient(to bottom,
  #7db5dc 0%,   /* 近水面透亮 */
  #0a5a99 45%,  /* 中层海水 */
  #000000 100%  /* 深渊 */
)
```

冰面受光方向固定为**左上落日、右下深蓝**：受光面冰蓝带一点橙光，阴影面深海蓝，绝不能上下颠倒。

## 3. 流体原则

「流体」不是指必须用 WebGL，而是指一种视觉态度：**没有生硬边界，光、水、形、时间都可以流动。**

### 3.1 流体即光

- 橙色和蓝色都以径向渐变光晕出现，不以硬边色块出现。
- 液态模式色板以深蓝为主体、橙色为稀缺点缀：

```text
#000000 → #0a5a99 → #7db5dc → #ffb36f → #ff6a06
```

- 页面局部光晕可参考主图的 `radial-gradient` 软边写法，橙色光晕控制在页面 1–2 处。

### 3.2 流体即水

- 水线是画面的水平基准：主图水面位于画布约 **30%** 高度。
- 波浪用连续贝塞尔曲线分层叠加：底层慢、上层稍快，两层色差保持在深海蓝与黑之间（如 `#0a5a99` 与 `#000000`）。
- 界面中的分隔线优先使用极低透明度白线（`--white-04/05/06`），它应当像「冰面裂痕」而不是厚重边框。

### 3.3 流体即形

- 卡片、弹窗、标签统一圆角：卡片 14–16px，标签可用胶囊（`rounded-full`）。
- 避免直角大面板和纯矩形拼贴；需要边界时使用 1px 半透明白边框 + 轻微白底。
- 容器使用玻璃语言：`bg-white-02/03` + `border-white-05/06`，hover 提升到 `bg-white-04/05` + `border-white-12`。

### 3.4 流体即时间

- 背景呼吸 6–10s，波浪平移 25–35s，液态 shader `speed` 保持低值（默认 `0.2`）。
- 内容交互 0.15–0.25s；页面入场 0.3–0.5s；禁止长时间的夸张缓动。
- 滚动时背景动画暂停，离开立即恢复；`prefers-reduced-motion` 下全部关闭或瞬移。

## 4. 构图

### 4.1 冰山主体

- 冰山必须**非对称双峰**，主体偏右、重心偏下，峰脊错落，不要规则三角形。
- 水下体量应大于水上可见部分；水下轮廓上宽下收，向深渊聚拢。
- 橙色落日反光只能落在受光边的小三角面上，不覆盖整个冰面。

### 4.2 页面层次

```
前景：内容 / 玻璃卡片 / 焦点环
中景：文字、结构线（白透明度）
背景：冰山海面 / 液态渐变 / 光晕（纯装饰，pointer-events: none）
```

- 背景只讲故事，不抢内容；任何背景组件都必须 `aria-hidden` 且不拦截点击。
- 长页面下方允许向纯黑沉降：内容滚得越深，背景越接近深海。

## 5. 界面映射

### 5.1 页面头

- 标题：`2rem`、`font-black`、`text-white-92`、字距 `0.03em`。
- 引导文案：`text-white-35`，行高 1.6–1.7。
- 头图或装饰不得压在标题正后方，应偏移到一侧或仅作顶部光晕。

### 5.2 标签切换

- 胶囊标签：未选中透明底 `text-white-45`，hover 轻提亮；选中 `bg-white-10` + `border-white-16` + `text-white-90`。
- 标签条吸顶时用 `bg-surface` + 下边框 `border-white-06`，不加投影。

### 5.3 卡片

```text
默认：rounded-xl  border-white-06  bg-white-02  padding 20px
hover：border-white-12  bg-white-04  上浮 -2px
空态：border-dashed border-white-08  bg-white-02
```

- 卡片标题 `text-base font-bold text-white-85`。
- 正文 `text-sm text-white-40`，行高 1.7–1.85。
- 分类可用分类色小圆点；标签可用 emoji；两者都只做小尺寸装饰。

### 5.4 文字

- 只用五级字号：`micro 10px / tiny 11px / xs 12px / sm 14px / base 16px`。
- 白色透明度阶梯即层级：标题 `85–92`，正文 `40–55`，辅助 `30–45`，不可读装饰可低于 `20`。
- 正文背景必须保证可读性；深蓝底上不要叠深灰文本。

### 5.5 弹窗与抽屉

- 基底 `#111111`，边框 `--white-08`，圆角 16px。
- 标题栏 sticky，关闭按钮触摸热区 ≥ 40px。
- 弹窗是「从深海浮出的冰片」：轻、薄、可关闭，不铺满全屏。

## 6. 动效

- 只动 `opacity / transform / color / background`，不写全局 `transition: all`。
- 统一使用 `--ease-out / --ease-standard / --ease-emphatic / --ease-hero / --ease-float`。
- 悬停优先「提亮 + 微移」，不要弹跳、摇晃、持续闪烁。
- 背景层保持低频呼吸；内容层保持快速反馈。两者节奏不能互换。
- `prefers-reduced-motion: reduce`：背景停帧、过渡归零、平滑滚动改为瞬移。

## 7. 禁忌

- ❌ 大面积纯白 / 浅色卡片堆叠（会打破深海语境）。
- ❌ 橙色铺满背景或大按钮（橙色是火光，不是壁纸）。
- ❌ 蓝橙 50/50 强对比撞色。
- ❌ 直角大面板、粗边框、厚重投影、霓虹绿 / 霓虹紫等外部色。
- ❌ 背景动画无休止地高频运动，或滚动时仍抢占 GPU。
- ❌ 每张卡片都做 `backdrop-filter` / 大半径 `blur()`（只在弹窗遮罩等少量场景使用）。
- ❌ 硬编码任意字号、任意 `rgba(255,255,255,α)`；使用 `--font-*` 与 `--white-*`。

## 9. 评审清单

新页面 / 新组件合入前逐项确认：

- [ ] 深蓝黑为基底，白色透明度承担信息层级。
- [ ] 橙色仅用于焦点与状态，总面积不超过 10%。
- [ ] 至少有一种「流体」手段：光晕 / 波浪 / 液态渐变 / 软边胶囊，且背景不拦截交互。
- [ ] 卡片与标签遵循玻璃容器规范，无直角大面板。
- [ ] 动效使用缓动令牌，背景低频、内容快速，滚动暂停。
- [ ] `prefers-reduced-motion` 与移动端触摸热区已覆盖。
- [ ] 未硬编码字号与白色透明度。
