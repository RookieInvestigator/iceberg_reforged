## v5.8.3 — 2026-10-27 — 3D 聚焦修复与正文字内标记

### 新增

- 词条正文支持行内富文本：`==强调==`、`**加粗**`、`*斜体*`、`[文字](链接)`，并新增引用块（连续 `> ` 开头的段落渲染为带左侧竖线的引用）。解析与渲染统一到 `lib/richText` + `ui/RichText`，冰山图卡片 / 移动抽屉 / 悬停气泡 / 3D 面板 / 深潜面板 / 手册共用同一套；古籍模式与导出降级为纯文本。

### 数据

- 从上游 API 同步：词条 1460 → 1461（新增「空中小滕王阁」），层级 8 / 分类 15 / 标签 70 不变；字形子集按新语料重建（去重 4223 字，CJK 3811）。
- 手册补齐 30 条「只有标题、没有正文」的标签释义（写作占位，渲染层按占位规则隐藏，覆盖守卫照常通过）。

### 改进

- 移动端 3D 冰山整体收口：聚焦机位按竖屏可见区拉近（3.5 → 2.6）让碎片读得清；底部详情面板改为 dvh 高度并加下滑关闭把手，换用 44px 触控关闭热区，面板内滚动不再带动整页；首次进入给出「拖动旋转 · 双指缩放 · 轻点碎片」提示；顶部返回/品牌按钮与面板底部让出刘海与 Home Indicator 安全区。
- 移动端渲染降载：关闭 MSAA、DPR 上限降到 1.75、Bloom 分辨率降到 32%、星点与冰尘各减约 40%；触屏不再做悬停拾取（此前每次触摸移动都会全量扫描实例）。
- 3D 冰山页不再显示顶部公告条（全屏画面被遮挡），沉浸式路由由 `meta.immersive` 标记。
- 仓库治理：协作指引与内部开发文档不再入库（只对外保留 README 与 CHANGELOG），第三方研究下载目录加入忽略列表。

### 修复

- 移动端 3D 冰山聚焦后看不到所选碎片：详情面板从底部升起盖住画面中心，聚焦镜头现在按面板实际遮挡高度把目标上移到可见区中心（桌面侧边面板行为不变）。
- 按当前语料重新子集化 7 个字体文件：语料此前已有增改但未重跑脚本，字体新鲜度门禁（CI 会拦部署）一直为红。

## v5.8.1 — 2026-10-18 — 术语表导航重做

### 新增

- 抽出一个共享的导航显隐规则模块（顶部热区、页顶常显、触屏常显、上滚显 / 下滚隐、±10px 防抖），冰山图筛选栏与术语表导航共用同一套判断，附单测。

### 改进

- 术语表吸顶导航重做：三选项卡等分铺满（移动端三个标签都完整可见），字母条两端对齐、窄屏横向滚动时裁切边内缩到面板内侧。
- 导航未贴住时保持透明、贴住后浮成卡片，与冰山图筛选栏同一表面语义；下滚隐藏、上滚与悬停顶部热区时显形。
- 「返回首页」从导航里移到标题上方，做成与 3D / 深潜页一致的面包屑。
- 术语表正文改为自动回流：普通换行按中英文规则并回一段，想强制断行时行尾留两个空格（或反斜杠），空行分段；不再被手工折行切成半句。
- 术语表源文件按标准 Markdown 重排：句末断行写成行尾反斜杠（20 处），其余手写折行并回成段，空行表示分段。
- 术语表可读性：正文对比度提到可读区间、条目间距加大、首字母分组头显示该组条目数。
- 术语表分段渲染：一个段落一个 `<p>`，段内换行紧接下一行、分段靠段间距拉开（不做首行缩进），换行与分段在视觉上可区分。
- 术语表词条正文支持行内标记：`==强调==`、`**加粗**`、`*斜体*`（可嵌套，未闭合按普通文字处理），作者约定写进 `handbook.md` 头部注释。

### 修复

- 术语表自动隐藏还没有解释的词条（正文仍是「待补充」占位），条目数与字母跳转随之收敛。
- 删掉宽屏右侧目录：可见词条仅 21 条、页面约 3 屏时，字母跳转已到词条级粒度，目录只是复述内容。

## v5.8.0 — 2026-10-10 — 副表体系成型 · 贡献闭环 · 标记与提示统一 · v1 归档

### 新增
- 副表重组为「一表一域」六张表：标量字段、分类、链接、关联、署名、标记各占一张，一块数据只有一个写入入口。

- 反馈审核工作台集中处理用户提交，逐条对照现值与建议值，决定后一键生成副表并回填审核状态。

### 改进
- 副表编辑器改为所见即所得：标题、描述、分类、标签、链接、关联词条均在预览里就地修改，改动落到对应副表。
- 署名自成一表，词条详情页脚显示「由谁补充」，不再逐条罗列改过哪些字段。
- 徽章释义与标记备注的悬浮提示合并为同一组件与同一套样式，并随深色／浅色阅读表面反色。
- 站点域名收敛为唯一真值，导航、预渲染、站点地图与收录声明统一由它派生。
- 数据新旧改按内容指纹判定，仅当指纹不同才在页脚提示数据已更新。

### 修复
- 保存副表会误删仅有编号、其余字段为空的历史行，造成真实数据损失；现只丢弃本次新建且仍为空白的行。
- 移动端抽屉引用了未导入的组件，署名行静默不渲染，已补齐。
- 原始行编辑按各表实际列声明渲染，不再出现改了也不落盘的空控件。
- 收窄副表与上游数据的职责边界，订正角标覆盖分类与链接的修正；未订正的词条不再出角标。

### 移除
- 第一代主图整批归档并移出仓库，旧版路由保留为跳转，旧书签不会失效。

### 数据
- 词条刷新为 1454 条，含一处描述补全与标题、描述各一处修订；字体子集同步，字形集 4218 字符。
