# 更新日志

每个版本一条：**版本号 — 日期 — 变更要点**。日期以 git 提交为准，版本号沿用历史编号，
早期未编号的发布按时间顺序补号。只记读者关心的结论，实现细节见提交历史。

## v6.0.0 — 2026-11-28 — 主图换代 V3 · 词条星图无限卷轴 · 语义实体四维 · 数据与字形同步

### 主图换代

- **`/` 现在是 V3 主图**（第三代实现）；旧版主图整体迁往 `/legacy`
  （`/v2` 重定向到 `/legacy`，`/v3` 重定向到 `/`，`/minimal` 同步指向 `/legacy`）。
- V3 核心架构：词条墙**不经过 Vue**——命令式渲染器一次 `DocumentFragment` 拼装、
  零 diff；筛选走 `Uint8Array` 状态差分，只对真正翻转的元素写 DOM；
  分类色/错落全部走样式表类名，零内联样式；整墙事件全部委托（1 click + 1 pointerover + 1 keydown）；
  描边用 `paint-order: stroke fill` 一次绘制；进场用 `animation-timeline: view()`
  滚动驱动（`@supports` 包裹带回落）；详情用原生 `<dialog>`；筛选管线改谓词数组。
- 功能覆盖旧版全部能力（搜索 / 筛选 / 排序 / 已读 / NEW / 收藏 / 深链 / 探索轨迹 /
  引号风格 / 深浅阅读表面 / 键盘操作），另新增快捷键全表、收藏/已读可视化统计、
  深入模式、悬停卡缓隐。
- 预渲染为 `/legacy` 生成静态壳，sitemap 主条目指向 `/`；
  「历史上的今天」返回链接统一回 `/legacy`，主图与 legacy 两条路由都走弹窗打开词条。

### 词条星图（`/stars`）

- 星图从 DEV 专属转为正式沉浸式路由（旧路径 `/words` 重定向），Home 主卡区
  星图顶替 3D 冰山位置，3D 降为文字入口；预渲染与 sitemap 补 `/stars`。
- **无限卷轴为单遍环形回绕**：世界以星群真实包围盒 ×1.015 为周期，
  每个元素只取离视口中心最近的一个副本——每帧绘制量从 9 遍降到 1 遍，
  同时修掉「只有中间那片能点」「他片同名点跟着亮」「一次只显示一片的文字」三个问题。
- 连线两端**成对回绕**（先定 A 的副本，B 相对 A 取最短），修掉回绕分界处
  连线横穿全屏的错位；只保留星座内部骨架连线，跨星座背景线移除。
- 缩放下限动态取「一屏恰好一个周期」，防止视野大于周期时露出空带。
- 布局：星座中心抖动网格铺满全域；游离星按语义亲和度聚类并按座限载，
  密度均匀度显著提升。

### 语义实体系统（词条星图的关联引擎）

- 新增四维实体抽取 `entityExtract.ts` + `entities.csv` 副表：**地名 / 时间 / 核心名词 / 发布平台**，
  供星图建图与关联评分使用；`EdgeReasonKind` 相应扩展。
- **平台单列维度**（天涯 / 贴吧 / 微博 / 知乎 / B站…），权重约为普通名词的 1.1 倍；
  17 个具体贴吧名白名单（2012吧 / 都市传说吧 / 灵异吧 等）连同「吧友 / 吧主」泛指归并到贴吧。
- **领域同义词归并**（`NOUN_ALIAS`，225 条，沿别名链归一到底）：
  年号→朝代（洪武/永乐/嘉靖/万历→明代，康熙/乾隆→清代，细分期与父朝代共现）、
  鬼魂族→幽灵、尸族→尸体、`QQ空间→QQ`、`航班/机场→航空`、`通灵游戏/笔仙/碟仙→通灵`、
  `梗/迷因/meme→模因`、精神疾病群→精神障碍、剧种→戏剧、船名→船舶、启事类→张贴物，
  以及 `华南虎→虎`、`胶片→照片`、`短片→电影`、`人体实验→实验`、`港漫→漫画` 等归并。
- 新增关键词：新闻、艺术、灭绝、实验、戏剧、船舶、张贴物、模因、月亮（月球/明月归并）；
  移除：论坛（平台表）、深海。
- 通用中文同义词库评估结论：不引入——通用词库在一词多义与领域术语上误合并率高，
  合并决策由领域词典人工兜底，词库只作候选发现。
