待完善。此占位专题展示了专题系统的完整功能：前端列表页按日期排序、详情页渲染正文并嵌入关联词条卡片、点击卡片弹出词条详情弹窗。

[item:87fbcd52]

在手写正文中可以使用 `[item:词条ID]` 标记，系统会自动将其渲染为内联词条卡片，支持分类色标题、分类名标签和描述截断。点击卡片可打开 ItemModal 弹窗，支持前后导航和相关推荐。

[item:be29bf68]

每篇专题在 frontmatter 中声明关联词条 ID 数组，由组件动态匹配 `iceberg.json` 中的真实数据。专题文件夹位于 `src/data/features/`，新增 `.md` 文件后自动出现在专题列表页。正文使用 Markdown 编写，支持标题、段落、列表、粗斜体、链接等基本语法。
