# 中文兔子洞冰山图

一个关于中文互联网奇闻异事、都市传说、超自然现象、真实犯罪、阴谋论与冷知识的冰山图目录。

## 访问

**[RookieInvestigator.github.io/iceberg_reforged](https://RookieInvestigator.github.io/iceberg_reforged/)**

## 功能

- **1343+ 词条**，8 个层级，16 个分类
- **Tooltip / 弹窗双模式**：hover 浮窗或点击详情面板
- **全文搜索**、分类/标签多维度筛选
- **词条排序**（默认 / A-Z / 按分类）
- **相关词条推荐**：基于分类、标签、标题相似度
- **古籍模式**：仿线装书竖排阅读，按类别或层级分卷
- **历史上的今天**：历史奇闻日历
- 中 / English / 日本語 三语界面
- 动态冰山背景（可选开启）
